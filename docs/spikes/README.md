# API スパイク記録（付録B）— 公開版では非公開

開発リポジトリでは、GMO FX API の仕様のうち公式ドキュメントだけでは確定できない点を、
参照系の GET（必要な場合のみ最小ロットの実発注）で確かめ、その結果をこのディレクトリに記録しています。
実装はこの記録を根拠に書き、推測では書きません（[AGENTS.md](../../AGENTS.md) の最重要原則）。

記録には公式ドキュメントの引用や実際の口座の応答が含まれるため、公開版には含めていません。
コード中の `docs/spikes/...` への参照は非公開側のファイルを指しています。

## 記録していたテーマ（要約）

| テーマ | 確かめたこと |
|---|---|
| 口座資産（assets） | ロット計算に使う純資産・余力のフィールド名と型 |
| ローソク足（klines） | 日足・4 時間足の取得単位、tick size、最小乖離 |
| IFD-OCO 発注（ifoOrder） | 必須フィールドと、指値・逆指値の指定方法 |
| 取消・決済（cancelOrders / closeOrder） | パラメータの形と上限件数。建玉の一括決済エンドポイントは FX API に無いこと |
| 約定明細（executions / latestExecutions） | 取得できる範囲（直近 1 日）、エラーが HTTP 200 で返ること、決済約定が別の注文 ID になること |
| 閉場中の挙動 | 閉場中も参照系 GET は成功を返すため、市場の開閉は専用のステータス API で判定する必要があること |
| 決済と注文枠・反映遅延 | 決済 OCO を残したまま決済できるか、取消が反映されるまでの時間 |
| ロンドン ORB の前提 | ORB のルールを組める注文種別、閉場中の ticker の挙動 |

スパイクの手順は [.claude/commands/api-spike.md](../../.claude/commands/api-spike.md)、
実行に使うスクリプトは [scripts/](../../scripts/)（`spike_*.py`）にあります。
